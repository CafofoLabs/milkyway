# Branding

The selected identity is **Orbital Terminal**: a terminal prompt inside an orbit, with an orange satellite. It connects MilkyWay to the terminal symbol in the Cafofo Labs identity.

## Assets

- `assets/milkyway-light.png`: for light surfaces; ivory background.
- `assets/milkyway-dark.png`: for dark surfaces; navy background.

These are raster PNG assets with opaque backgrounds, not SVG masters. The README selects the appropriate theme automatically. Preserve the aspect ratio and surrounding clear space.

Transparent generation produced visible edge artifacts and was excluded. Clean transparent and vector masters remain future refinements; the visual identity is approved.

## Generation

Created with the built-in image generation tool, then visually inspected. The approved direction came from three concepts: Galactic Core, Constellation, and Orbital Terminal.

Final prompt specification: reproduce the approved orbital terminal emblem and exact `MilkyWay` wordmark as one centered horizontal lockup, with an orange chevron and satellite, generous padding, and a 3:1 aspect ratio. Use midnight teal on ivory for light mode, and ivory on midnight navy for dark mode. Preserve the geometry and typography; exclude labels, decorative effects, and extra text.

Target palette: orange `#FF8500`, midnight teal `#16313B`, ivory `#F5EFE4`, and midnight navy `#101D27`. Generated raster colors may vary slightly.
